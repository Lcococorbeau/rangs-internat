Lecture rapide

Plus le rang est élevé, plus la combinaison spécialité–ville reste accessible loin dans le classement. En mode « Toutes les villes », le rang max le plus élevé de la spécialité est retenu à chaque tour.

Mode « Toutes les villes »

Pour chaque spécialité, le graphique conserve à chaque tour le rang max le plus élevé parmi toutes les subdivisions. L’infobulle indique la ville correspondante, y compris en cas d’égalité.

Comparaisons multiples

Les sélections sont croisées : n spécialités × m villes = n × m combinaisons. Une combinaison sans donnée sur toute l’année est indiquée « inexistant » et ne trace pas de courbe.

Données issues des fichiers de suivi des tours de simulation EDN. Une valeur absente dans le fichier source reste absente sur le graphique.
