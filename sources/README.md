# Fichiers XLSX sources

Créer un sous-dossier par année, puis déposer les tours dedans.

Exemple :

- `sources/2026/Tour 1.xlsx`
- `sources/2026/Tour 2.xlsx`
- `sources/2026/Tour 3.xlsx`
- `sources/2026/Tour Def.xlsx`

À chaque déploiement Vercel, le script relit automatiquement tous les fichiers présents et reconstruit l'année. Les tours déjà déposés doivent donc rester dans le dossier.
